## 使用流程

### 1. 首次使用
```bash
# 安装依赖
pip install -r requirements.txt

# 配置环境变量
export QWEN_API_KEY="your_api_key"

# 构建索引
python main.py build --limit 100
```

### 2. 日常使用
```bash
# 生成文书
python main.py generate \
    --evidence "evidence.txt" \
    --type "起诉书" \
    --output "complaint.txt"

# 检索法律
python main.py search --query "民间借贷" --top-k 5

# 评估文书
python main.py evaluate \
    --document "complaint.txt" \
    --evidence "evidence.txt" \
    --type "起诉书"
```

### 3. 验证系统
```bash
# 运行验证脚本
python verify.py

# 运行示例
python example.py
```

## 配置说明

所有配置都在 `bootstrap.yaml` 中：

- **LLM 配置**: 模型选择、API 配置
- **RAG 配置**: 嵌入模型、向量数据库、检索参数
- **数据集配置**: 法律法规路径
- **多模态配置**: 视频、图像、音频处理参数
- **Agent 配置**: 工具列表、推理模式
- **文书生成配置**: 输出目录、模板目录
- **评估配置**: 评审标准、评判配置
- **日志、缓存、性能配置**

## 扩展指南

### 添加新文书类型
1. 在 `templates/` 创建模板文件
2. 在 `bootstrap.yaml` 添加类型
3. 在 `DocumentGenerator` 添加生成逻辑

### 自定义解析器
继承 `MultimodalParser` 类

### 添加新工具
创建新的 `Tool` 类

## 技术栈

- **LLM**: Qwen-Max / Qwen-VL
- **Embedding**: BGE-m3
- **Reranker**: BGE-Reranker-v2
- **Vector DB**: Milvus / Qdrant
- **ASR**: Whisper / SenseVoice
- **OCR**: PaddleOCR
- **Framework**: Python + PyTorch

## 注意事项

1. **API Key 安全**: 使用环境变量，不要提交到代码仓库
2. **向量数据库**: 确保 Milvus/Qdrant 服务正常运行
3. **数据集路径**: 检查 `bootstrap.yaml` 中的路径配置
4. **文书质量**: 生成的文书仅供参考，需由专业律师审核
