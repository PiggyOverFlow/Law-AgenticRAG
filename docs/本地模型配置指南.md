# 本地模型配置指南

## 概述

本系统支持将 BGE 模型下载到本地目录，并从本地加载模型。这样可以：
- 避免重复下载
- 提高加载速度
- 离线使用模型
- 节省网络带宽

## 配置说明

### 1. 修改配置文件

在 `bootstrap.yaml` 中配置本地模型路径：

```yaml
rag:
  embedding_model: "BAAI/bge-m3"  # Hugging Face 模型名称（备用）
  embedding_model_path: "/app/model/bge-m3"  # 本地模型路径（优先使用）
  reranker_model: "BAAI/bge-reranker-v2-m3"  # Hugging Face 模型名称（备用）
  reranker_model_path: "/app/model/bge-reranker-v2-m3"  # 本地模型路径（优先使用）
  use_local_model: true  # 是否使用本地模型
```

### 2. 配置参数说明

- `embedding_model`: Hugging Face 上的嵌入模型名称（当本地模型不可用时使用）
- `embedding_model_path`: 本地嵌入模型保存路径
- `reranker_model`: Hugging Face 上的重排序模型名称（当本地模型不可用时使用）
- `reranker_model_path`: 本地重排序模型保存路径
- `use_local_model`: 是否优先使用本地模型（true/false）

### 3. 加载逻辑

系统按照以下优先级加载模型：

1. 如果 `use_local_model = true` 且本地路径存在 → 使用本地模型
2. 如果本地路径不存在 → 回退到 Hugging Face 下载
3. 如果 Hugging Face 下载失败 → 使用模拟模型（全零向量）

## 下载模型到本地

### 方法 1：使用下载脚本（推荐）

下载脚本默认使用国内镜像源（https://hf-mirror.com）加速下载。

```bash
# 下载所有模型（使用国内镜像源）
python utils/download_models.py

# 只下载嵌入模型
python utils/download_models.py --model embedding

# 只下载重排序模型
python utils/download_models.py --model reranker

# 自定义保存路径
python utils/download_models.py --path /custom/path/to/models

# 不使用国内镜像源（直接从 Hugging Face 下载）
python utils/download_models.py --no-mirror
```

### 方法 2：使用 Hugging Face CLI

```bash
# 安装 huggingface-cli
pip install huggingface_hub

# 下载嵌入模型
huggingface-cli download BAAI/bge-m3 --local-dir /app/model/bge-m3

# 下载重排序模型
huggingface-cli download BAAI/bge-reranker-v2-m3 --local-dir /app/model/bge-reranker-v2-m3
```

### 方法 3：使用 Python 代码

```python
from transformers import AutoTokenizer, AutoModel, AutoModelForSequenceClassification

# 下载嵌入模型
tokenizer = AutoTokenizer.from_pretrained("BAAI/bge-m3", trust_remote_code=True)
model = AutoModel.from_pretrained("BAAI/bge-m3", trust_remote_code=True)

tokenizer.save_pretrained("/app/model/bge-m3")
model.save_pretrained("/app/model/bge-m3")

# 下载重排序模型
tokenizer = AutoTokenizer.from_pretrained("BAAI/bge-reranker-v2-m3", trust_remote_code=True)
model = AutoModelForSequenceClassification.from_pretrained("BAAI/bge-reranker-v2-m3", trust_remote_code=True)

tokenizer.save_pretrained("/app/model/bge-reranker-v2-m3")
model.save_pretrained("/app/model/bge-reranker-v2-m3")
```

## 使用本地模型

### 1. 启用本地模型

确保 `bootstrap.yaml` 中设置：

```yaml
rag:
  use_local_model: true
```

### 2. 验证本地模型

```bash
# 检查模型文件是否存在
ls -la /app/model/bge-m3
ls -la /app/model/bge-reranker-v2-m3

# 测试模型加载
python test_bge_models.py
```

### 3. 运行系统

```bash
# 构建索引（使用本地模型）
python main.py build --limit 100

# 生成文书
python main.py generate --evidence "evidence.txt" --type "起诉书"
```

## 常见问题

### Q1: 如何切换回 Hugging Face 模型？

A: 修改 `bootstrap.yaml`：

```yaml
rag:
  use_local_model: false
```

### Q2: 本地模型路径可以自定义吗？

A: 可以，修改 `bootstrap.yaml` 中的路径：

```yaml
rag:
  embedding_model_path: "/custom/path/to/bge-m3"
  reranker_model_path: "/custom/path/to/bge-reranker-v2-m3"
```

### Q3: 如何更新本地模型？

A: 重新下载模型到相同路径即可：

```bash
python utils/download_models.py --model embedding
```

### Q4: 本地模型占用多少空间？

A: 
- BGE-M3: 约 2.2 GB
- BGE-Reranker-v2-m3: 约 1.1 GB
- 总计: 约 3.3 GB

### Q5: 可以只下载部分模型吗？

A: 可以，使用 `--model` 参数：

```bash
# 只下载嵌入模型
python utils/download_models.py --model embedding

# 只下载重排序模型
python utils/download_models.py --model reranker
```

### Q6: 下载速度慢怎么办？

A: 下载脚本默认使用国内镜像源（https://hf-mirror.com）加速下载，无需额外配置。如果需要禁用镜像源，可以使用：

```bash
python utils/download_models.py --no-mirror
```

如果仍然需要手动设置环境变量（例如在其他脚本中使用），可以：

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

### Q7: 如何删除本地模型？

A: 直接删除目录：

```bash
rm -rf /app/model/bge-m3
rm -rf /app/model/bge-reranker-v2-m3
```

## 性能对比

| 模式 | 首次加载 | 后续加载 | 网络依赖 |
|------|----------|----------|----------|
| Hugging Face | 慢（需下载） | 慢（需下载） | 是 |
| 本地模型 | 快（直接加载） | 快（直接加载） | 否 |

## 最佳实践

1. **首次使用**：先下载模型到本地
2. **生产环境**：始终使用本地模型
3. **开发环境**：可以使用 Hugging Face 模型
4. **定期更新**：定期下载最新版本的模型
5. **备份模型**：将本地模型备份到其他位置

## 故障排除

### 问题 1：本地模型加载失败

**错误信息**：`本地模型路径不存在: /app/model/bge-m3`

**解决方案**：
```bash
# 下载模型
python utils/download_models.py

# 或检查路径配置
ls -la /app/model/bge-m3
```

### 问题 2：模型文件损坏

**错误信息**：`OSError: Can't load tokenizer for 'BAAI/bge-m3'`

**解决方案**：
```bash
# 删除损坏的模型
rm -rf /app/model/bge-m3

# 重新下载
python utils/download_models.py --model embedding
```

### 问题 3：权限问题

**错误信息**：`Permission denied: '/app/model/bge-m3'`

**解决方案**：
```bash
# 检查权限
ls -la /app/model

# 修改权限
chmod -R 755 /app/model
```
