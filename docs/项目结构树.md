## 目录说明

### 根目录文件
- **bootstrap.yaml**: 系统主配置文件，所有配置集中在此
- **config.py**: 配置管理模块，支持环境变量替换
- **main.py**: 命令行主入口，提供 CLI 接口
- **example.py**: 使用示例，演示系统功能
- **verify.py**: 系统验证脚本，检查各模块是否正常
- **setup.sh**: 快速启动脚本，自动化初始化

### src/ 源代码目录
包含所有核心功能模块：
- **models/**: 数据模型定义
- **parsers/**: 多模态文件解析
- **rag/**: RAG 检索实现
- **agent/**: Agent 推理逻辑
- **data/**: 数据加载和处理
- **generation/**: 文书生成
- **evaluation/**: 评估框架

### dataset/ 数据集目录
包含法律法规数据：
- **Laws-master/**: 法律法规数据集
- **scripts/**: 数据处理脚本
- 各类法律分类目录

### templates/ 模板目录
包含各类法律文书模板

### output/ 输出目录
存放生成的法律文书

### logs/ 日志目录
存放系统运行日志

### tests/ 测试目录
包含单元测试和集成测试

### docs/ 文档目录
包含项目文档和说明

## 文件统计

- **总文件数**: 30+ 个核心文件
- **代码行数**: 3000+ 行
- **模块数量**: 8 个主要模块

## 核心功能模块

1. **配置管理** (config.py)
2. **数据模型** (src/models/)
3. **多模态解析** (src/parsers/)
4. **RAG 检索** (src/rag/)
5. **Agent 推理** (src/agent/)
6. **数据加载** (src/data/)
7. **文书生成** (src/generation/)
8. **评估框架** (src/evaluation/)

## 技术架构

```
用户输入（多模态证据）
    ↓
多模态解析 (parsers/)
    ↓
案件事实结构化 (models/)
    ↓
Agent 推理 (agent/)
    ├→ RAG 检索 (rag/)
    ├→ 模板检索 (templates/)
    └→ 事实提取 (models/)
    ↓
文书生成 (generation/)
    ↓
评估反馈 (evaluation/)
```
