# 本地模型快速开始

## 5 分钟快速配置

### 第一步：下载模型

```bash
# 下载所有 BGE 模型到 /app/model（默认使用国内镜像源）
python utils/download_models.py

# 或分别下载
python utils/download_models.py --model embedding
python utils/download_models.py --model reranker

# 如果不使用国内镜像源
python utils/download_models.py --no-mirror
```

### 第二步：验证模型

```bash
# 检查模型文件
ls -la /app/model/bge-m3
ls -la /app/model/bge-reranker-v2-m3

# 测试模型加载
python test_bge_models.py
```

### 第三步：配置使用本地模型

确保 `bootstrap.yaml` 中设置：

```yaml
rag:
  use_local_model: true  # 启用本地模型
  embedding_model_path: "/app/model/bge-m3"
  reranker_model_path: "/app/model/bge-reranker-v2-m3"
```

### 第四步：运行系统

```bash
# 构建索引（使用本地模型）
python main.py build --limit 100

# 生成文书
python main.py generate \
    --evidence "evidence.txt" \
    --type "起诉书"
```

## 切换模型加载方式

### 使用本地模型

```yaml
rag:
  use_local_model: true
```

### 使用 Hugging Face 模型

```yaml
rag:
  use_local_model: false
```

## 自定义模型路径

如果模型保存在其他位置，修改 `bootstrap.yaml`：

```yaml
rag:
  embedding_model_path: "/custom/path/to/bge-m3"
  reranker_model_path: "/custom/path/to/bge-reranker-v2-m3"
```

## 常见问题

### Q: 下载模型需要多长时间？

A: 取决于网络速度，通常：
- BGE-M3: 10-30 分钟
- BGE-Reranker-v2-m3: 5-15 分钟

### Q: 模型占用多少空间？

A: 
- BGE-M3: 约 2.2 GB
- BGE-Reranker-v2-m3: 约 1.1 GB
- 总计: 约 3.3 GB

### Q: 如何使用国内镜像加速下载？

A: 下载脚本默认使用国内镜像源（https://hf-mirror.com）加速下载，无需额外配置。如果需要禁用镜像源，可以使用：

```bash
python utils/download_models.py --no-mirror
```

如果仍然需要手动设置环境变量（例如在其他脚本中使用），可以：

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

### Q: 本地模型加载失败怎么办？

A: 检查以下几点：

1. 模型文件是否完整
2. 路径配置是否正确
3. 文件权限是否正确

```bash
# 检查模型文件
ls -la /app/model/bge-m3

# 检查权限
chmod -R 755 /app/model

# 重新下载
python utils/download_models.py --model all
```

### Q: 如何更新本地模型？

A: 重新下载模型到相同路径：

```bash
python utils/download_models.py --model all
```
