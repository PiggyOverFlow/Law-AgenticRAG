# 快速开始指南

## 5 分钟快速上手

### 第一步：安装依赖

```bash
# 克隆项目
git clone <repository_url>
cd LawRAG

# 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

### 第二步：配置系统

```bash
# 复制配置文件（如果不存在）
cp bootstrap.yaml bootstrap.yaml.example

# 设置环境变量
export QWEN_API_KEY="your_api_key_here"
```

### 第三步：构建索引

```bash
# 测试模式：只处理 10 部法律
python main.py build --limit 10

# 指定 CUDA 1、4、7 号卡运行（如多卡服务器，需设置 CUDA_VISIBLE_DEVICES）
CUDA_VISIBLE_DEVICES=1,4,7 python main.py build --limit 10

# 生产模式：处理所有法律（需要较长时间）
python main.py build
```

### 第四步：生成文书

```bash
# 创建测试证据文件
cat > ./dataset/evident/evidence.txt << EOF
2024年1月15日，被告李四向原告张三借款人民币10万元，约定月利率2%，借款期限为3个月。
借款到期后，被告未按约定归还借款本金及利息。
EOF

# 生成起诉书
python main.py generate \
    --evidence "evidence.txt" \
    --type "起诉书" \
    --request "要求被告偿还借款本金10万元及利息" \
    --output "complaint.txt"

# 查看生成的文书
cat output/documents/complaint.txt
```

### 第五步：检索法律

```bash
# 检索相关法条
CUDA_VISIBLE_DEVICES=6 python main.py search --query "民间借贷纠纷" --top-k 3
```

## 命令行参考

### 构建索引

```bash
python main.py build [OPTIONS]

选项:
  --limit INTEGER    限制处理的法律数量（用于测试）
```

### 生成文书

```bash
python main.py generate [OPTIONS]

必需参数:
  --evidence TEXT    证据文件路径（多个文件用逗号分隔）
  --type TEXT        文书类型（起诉书/答辩状/上诉状/申请书/代理词）

可选参数:
  --request TEXT     用户需求
  --output TEXT      输出文件名
  --no-save          不保存文件，直接输出到控制台
```

### 检索法律

```bash
python main.py search [OPTIONS]

必需参数:
  --query TEXT       检索查询

可选参数:
  --top-k INTEGER    返回结果数量（默认：5）
```

### 评估文书

```bash
python main.py evaluate [OPTIONS]

必需参数:
  --document TEXT    生成的文书路径
  --evidence TEXT    原始证据路径
  --type TEXT        文书类型

可选参数:
  --reference TEXT   参考文书路径
```

## 故障排除

### 问题 1：向量数据库连接失败

**错误信息**：`Connection refused` 或 `Unable to connect to Milvus`

**解决方案**：
```bash
# 检查 Milvus 是否运行
docker ps | grep milvus

# 启动 Milvus（使用 Docker）
docker run -d --name milvus-standalone \
  -p 19530:19530 \
  -p 9091:9091 \
  milvusdb/milvus:latest

# 或使用 Qdrant（替代方案）
# 修改 bootstrap.yaml 中的 vector_db.type 为 "qdrant"
```

### 问题 2：LLM 调用失败

**错误信息**：`API key not found` 或 `Authentication failed`

**解决方案**：
```bash
# 检查环境变量
echo $QWEN_API_KEY

# 重新设置
export QWEN_API_KEY="your_api_key_here"

# 或在 bootstrap.yaml 中直接设置（不推荐）
```

### 问题 3：索引构建很慢

**解决方案**：
```bash
# 使用 --limit 参数限制处理数量
python main.py build --limit 100

# 或使用 GPU 加速（需要安装 CUDA）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

### 问题 4：生成的文书质量不理想

**解决方案**：
1. 检查证据材料是否完整清晰
2. 调整 LLM 的 temperature 参数（降低温度提高准确性）
3. 使用评估系统分析问题所在
4. 由专业律师审核和修改
